# 🍰 Sweet Crumbs Bakery

A modern, responsive bakery landing page designed for a fictional bakery called **Sweet Crumbs**.

The website focuses on a warm, elegant visual style while providing a simple and user-friendly experience for customers to explore products and contact the bakery.

## ✨ Features

- 📱 Fully responsive design
- 🍰 Bakery product showcase
- 🖼️ Image gallery
- 📍 Contact information
- 💬 WhatsApp ordering button
- 📧 Email contact button
- 📱 Mobile hamburger navigation
- 🔗 Smooth navigation between sections
- 🎨 Modern and warm bakery-inspired design
- ⚡ Lightweight and fast-loading

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
